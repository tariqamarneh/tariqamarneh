### What I work on

- **A schema-driven agent for any business.** One agent that serves clinics, shops and service businesses from configuration instead of a new codebase per vertical.
- **Procedures.** A compiler that turns a business's plain-language workflow into a graph the agent executes step by step, plus the builder and runtime around it.
- **Production reliability.** Hunting a native memory leak with jemalloc heap profiles, taking a live AI codebase to strict mypy, and keeping LangSmith tracing useful while cutting its cost.
- **Knowledge bases.** Ingestion, retrieval, and detecting when two articles in a business's knowledge base contradict each other.
